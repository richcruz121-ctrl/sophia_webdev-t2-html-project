North Star Bakery - Touchstone Task 2

Open index.html in a browser, or upload this folder to GitHub Codespaces
and use its HTML preview. Keep the four HTML files together and leave the
media folder beside them. No CSS, JavaScript, or installation is needed.

The Word document is the single file requested for submission. This folder
is an extra working copy for reviewing and continuing the course project.

The bakery address, hours, prices, story, and staff descriptions are sample
content because the client scenario does not provide those details.
The form demonstrates HTML validation only and has no processing service.
Use sample data when trying it. Pickup date is optional so visitors can
send general questions without choosing a date. Preorder instructions ask
for a date; conditional validation would require a later development stage.

Review the four pages in your own GitHub Codespaces before submission.
Check navigation, image changes at 700px, audio controls, and form validation.
