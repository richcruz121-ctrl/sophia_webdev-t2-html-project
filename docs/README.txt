NORTH STAR BAKERY - TOUCHSTONE 3

This continues the four-page Touchstone Task 2 project. All pages share
styles.css. The HTML content, bakery media, and practice form are retained.

LOAD IN YOUR EXISTING CODESPACE
1. Upload and extract North_Star_Bakery_Touchstone3.zip in your project.
2. In the terminal, stop the old server with Ctrl+C.
3. Open a terminal in the extracted North_Star_Bakery_Touchstone3 folder.
4. Run: python3 -m http.server 8000
5. Open port 8000 in the browser and refresh the page.

TEST BEFORE SUBMISSION
- Open all four pages and click the navigation and preorder links.
- At about 375 pixels wide, check that sections stack and the page has
  no horizontal scrolling. Verify the form controls stay inside the page.
- At 1280 pixels wide, check the side-by-side home and contact layouts.
- Check images and the audio player. Tab through the links and form.
- Try an empty form, an invalid email, and item details under 10 characters.
- Use sample data only: the form has no order-processing service.

FINISH THE WORD TEMPLATE
- Add your public GitHub repository URL in Section 1.
- Commit and push the updated HTML, styles.css, and media to that repository.
- The supplied Codespaces preview URL is already in the document, but it
  currently requires sign-in. Check that your reviewer can access the
  preview and repository; a Codespaces preview also needs a running server.
- Insert an actual desktop screenshot of the updated home page in Section 4.
- Complete the pending preview checkbox and final review after testing.
- Submit the completed Word template as the single submission file.

DESIGN
Main colors: cream #FFF8F0, brown #6B3E26, peach #D88C5A,
charcoal #2F2A26. Fonts: Georgia and Arial, with generic fallbacks.
Mobile-first Flexbox; larger-screen media query at 48rem.
The featured picture switches image sources at 700 pixels.
